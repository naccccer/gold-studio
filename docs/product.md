# Gold Studio Product

## Purpose
Gold Studio helps users turn weak product and jewelry photos into premium studio-style images with minimal effort.

## MVP focus
- Mobile-first web app
- Farsi-first interface
- RTL by default
- Fast upload-to-result flow

## Core users
- Small jewelry sellers
- Small product sellers
- Admin operators managing credits and support

## MVP outcomes
- Upload a source photo
- Choose a style or output direction
- Generate an improved product image
- Review and download the result

## Non-goals for MVP
- Native mobile apps
- Team collaboration
- Automated billing
- Bulk workflows
