# Studio OVALA Brand Identity

## Direction
Quiet Atelier is the locked visual direction for Studio OVALA. The identity should feel premium, minimal, calm, image-led, and trustworthy. It should support jewelry, gold, watches, and luxury accessory photography without becoming flashy.

## Logo System
Source vectors are kept unchanged in `public/brand`:
- `Ovala Logo.svg`
- `Ovala studio-logo.svg`
- `Ovala-logo mark.svg`

- Use `public/brand/ovala-primary.svg` as the default stacked studio logo.
- Use `public/brand/ovala-horizontal.svg` only in wide placements where vertical space is tight.
- Use `public/brand/ovala-wordmark.svg` when the surrounding context already says studio.
- Use `public/brand/ovala-mark.svg` for compact brand moments.
- Use `public/brand/ovala-app-icon.svg` and `public/brand/ovala-favicon.svg` for square icon contexts.
- Use `public/brand/ovala-watermark.svg` for single-color marks on generated imagery at low opacity only.
- Use `public/brand/ovala-watermark-accent.svg` only when the champagne oval accent remains quiet against the image.
- Use `public/brand/ovala-primary-light.svg` on warm light surfaces and `public/brand/ovala-primary-dark.svg` on deep dark surfaces.

## Spacing And Size
- Keep clear space around every logo equal to at least half the compact oval mark width.
- Minimum primary logo width: 180px.
- Minimum horizontal lockup width: 260px.
- Minimum compact mark size: 32px.
- Minimum favicon size: 16px, using the favicon asset only.

## Colors
- Warm Ivory: `#F7F3EA`
- Soft Black: `#11100E`
- Champagne Gold: `#C7A96B`
- Stone Taupe: `#B8AEA0`
- Mist Gray: `#E6E1D8`

Use champagne gold sparingly: the oval accent, divider lines, selected states, and quiet highlight moments.

## Typography
- The OVALA logo is custom vector artwork.
- Use Vazirmatn for app UI and body text.
- Use Doran only for very short display titles.
- Keep letter spacing natural. Do not stretch UI text to imitate the logo.

## Image And Motifs
- Favor clean catalog/product photography, pale stone backgrounds, soft shadows, macro detail, and accurate material color.
- Reuse oval crops, thin divider lines, and subtle frame guides as brand motifs.
- Watermarks should sit quietly in a corner or on a neutral edge and should never compete with the product.

## Avoid
- Neon gradients, robots, magic wands, chat bubbles, obvious AI visuals.
- Diamond, crown, or perfume/fragrance references.
- Heavy black-and-gold luxury cliches.
- Nested cards, noisy borders, and generic SaaS dashboard presentation.
