Gold Studio visual direction (must persist across all UI phases):

This is not a startup SaaS dashboard.
This is a calm luxury AI creative studio.

Visual rules:
- Farsi-first, RTL-first, mobile-first.
- Minimal premium editorial feeling.
- Strong whitespace and breathing room.
- Warm ivory / soft white backgrounds.
- Charcoal text, muted stone borders.
- Muted champagne-gold accents only where needed.
- Avoid loud gradients, glows, neon, amber-dashboard clichés.
- Avoid too many rounded giant cards; use cleaner restrained geometry.
- Images and workflow should dominate, not metrics.
- Very few simultaneous decisions on screen.
- Typography should feel quiet, expensive, confident.
- Do not create generic Tailwind component-library looking layouts.
- Prefer custom composed premium spacing over template dashboards.
