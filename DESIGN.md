# Gold Studio Design System

## Overview

Gold Studio is a calm luxury product-photo studio, not a conventional SaaS dashboard. The interface should feel like a guided assistant for non-technical Farsi-speaking users: image-led, precise, mobile-first, and quietly premium. The default emotional tone is trust and control: the user brings an imperfect product photo, and the UI makes the path to a polished catalog image feel simple and inspectable.

The design avoids loud luxury clichés. It uses warm ivory space, soft black actions, large rounded photography, restrained champagne-gold details, and generous breathing room. Screens should feel curated rather than busy. Every view should answer one practical question: what image am I working with, what step am I on, and what is the next safe action?

The system has two coordinated modes. The everyday mode is warm, pale, and gallery-like. The project creation, processing, and result-review moments may shift into a near-black studio environment so the image feels like the hero object under controlled lighting.

## Colors

The palette is built from soft black, warm ivory, stone taupe, misted borders, and sparse champagne gold.

- Use warm ivory and off-white surfaces as the default canvas. Avoid pure white pages unless it is inside a contained card or photo overlay.
- Use soft black for primary actions and high-value text. It should feel editorial and grounded, never harsh or corporate.
- Use champagne gold as a small signal for selection, progress, dividers, badges, and the central creation action. It should not flood the interface.
- Use pale stone photo backgrounds behind jewelry and product imagery. These neutrals should support accurate material color and soft shadows.
- Use the near-black studio palette for focused generation and review flows. In this mode, white borders should be subtle and gold should become a confident action color.
- Use danger red only for destructive or failed states. Keep it muted and framed by soft warm backgrounds.

## Typography

Gold Studio is Farsi-first and RTL-first. Vazirmatn is the workhorse typeface for almost everything because it is readable at small mobile sizes and supports a calm instructional tone. Doran is reserved for very short display moments where a premium brand voice is useful.

Typography should be compact but not dense. Body copy uses generous line height because Persian UI text needs room to remain legible. Labels and captions stay small, but must be paired with clear spacing and icons rather than crowded into data-heavy blocks.

Do not use stretched, tracked-out UI text to imitate the logo. The brand can be expressive in the logo and image composition; the interface itself should prioritize legibility and confidence.

## Layout

The layout is mobile-first with a 393px reference width. Most user flows should read like a phone-native assistant: a top identity or context bar, one dominant image area, a small number of choices, and a persistent bottom action or tab bar.

Use large image blocks before controls whenever the image is the user's source, output, or decision object. Keep route-level files thin and component surfaces simple. Avoid stacking cards inside cards; use spacing, tonal layers, and one clear border instead.

Desktop layouts may widen to tablet or desktop containers, but they should preserve the mobile rhythm rather than becoming an analytics dashboard. Admin screens may be denser, but should still use the same warm surfaces, soft black actions, and champagne accents.

## Elevation & Depth

Depth is quiet and material rather than dramatic. Light screens rely on warm tonal contrast, thin ivory borders, translucent surfaces, and long low-opacity shadows. Photo cards can cast the strongest shadows because images are the primary content.

Studio-mode screens use depth differently: the dark background creates focus, while image frames use subtle white borders, black scrims, and restrained glow. Avoid heavy floating panels, glassmorphism as a main style, or stacked shadow systems that make the UI feel like a generic dashboard.

## Shapes

The shape language is soft, oval, and product-friendly. Most controls use 0.8rem to 1rem radii. Image frames and navigation shells use larger 1.45rem to 1.6rem radii. Fully round pills are used for badges, compact icon actions, and the central project creation button.

Use rounded forms consistently. Do not mix sharp rectangular controls with pill navigation in the same view. The softness should feel precise and expensive, not childish.

## Components

Primary actions are text plus icon, usually soft black on light surfaces. In dark studio flows, the main continue/create action may use a restrained gold gradient with dark text to feel active and tactile.

Secondary actions use pale surfaces, thin warm borders, and soft black or taupe text. Ghost actions are acceptable for low-risk navigation, but important choices should remain visibly tappable.

The mobile tab bar has five positions: home, gallery, centered new project, projects, and account. The centered new-project action is the most visually prominent navigation item. Active tabs use a warm soft surface rather than a loud color fill.

Image cards should be large, rounded, and minimally annotated. Use small overlay pills for metadata such as dates, selected state, or status. Overlays should be translucent and should not compete with product detail.

Inputs are understated: warm surface, thin border, medium radius, clear focus ring, and readable Farsi labels. Forms should feel like guided steps rather than a prompt-heavy tool.

## Do's and Don'ts

- Do lead with source and output imagery before controls.
- Do preserve RTL alignment, Farsi text, and readable Persian line height.
- Do use champagne gold sparingly for progress, selected states, and primary creation moments.
- Do keep project generation and result review focused, dark, and image-dominant when appropriate.
- Do make non-technical users feel guided with one clear next action per screen.
- Don't turn the app into a SaaS dashboard, prompt editor, admin panel, or form-heavy workflow.
- Don't use neon gradients, robots, magic wands, chat bubbles, perfume imagery, crowns, or heavy black-and-gold luxury clichés.
- Don't nest cards, add noisy filters, or scatter random one-off borders.
- Don't let decorative motion override clarity; all loops must respect reduced-motion preferences.
